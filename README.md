# OpenCode Mobile

Мобильный клиент [opencode](https://opencode.ai) для Android. Работает в двух режимах:

- **напрямую с провайдером** — ключ API вводится в приложении, запросы идут с телефона;
- **через сервер opencode** на компьютере — сессии, проекты и инструменты берутся с ПК.

Написан на Expo (bare workflow) и React Native.

## Возможности

- 182 провайдера и 6225 моделей из реестра [models.dev](https://models.dev), зашитых в сборку — список работает офлайн. Поддерживаются провайдеры с OpenAI-совместимым HTTP API.
- Инструменты модели: файлы в песочнице приложения, поиск в интернете и загрузка страниц, работа с облаками, настройка самого приложения.
- Облачные хранилища: Яндекс Диск, Google Drive, Dropbox. Для Google и Dropbox — OAuth с PKCE, у Яндекса — ручной токен.
- Вложения: фото, медиа и любые файлы с устройства. Изображения уходят в модель как `image_url` (нужна vision-модель), текстовые файлы — содержимым.
- Скачивание по ссылке и сохранение файла в память устройства через системный выбор папки.
- Светлая и тёмная темы, русский интерфейс.

## Запуск

```bash
npm install
npx expo prebuild --platform android   # создаёт папку android/
npx expo run:android
```

Папка `android/` не хранится в репозитории: `expo prebuild` генерирует её из `app.json`.

Релизная сборка:

```bash
cd android && ./gradlew assembleRelease
```

APK окажется в `android/app/build/outputs/apk/release/`. Обратите внимание, что release подписывается отладочным ключом Expo — для публикации в сторе сгенерируйте свой keystore.

### Сервер opencode на компьютере

```bash
opencode serve --hostname 0.0.0.0 --port 41111
```

Адрес для подключения — IP компьютера в локальной сети. Пароль берётся из `OPENCODE_SERVER_PASSWORD`; вспомогательный скрипт — `scripts/start-server.ps1`.

## Ключи и данные

В репозитории нет ключей API, токенов и client ID. Всё, что вводит пользователь, хранится только на устройстве в `expo-secure-store` и `AsyncStorage`. Для входа в Google Drive и Dropbox нужно завести собственные OAuth client ID и указать их в настройках приложения.

## Структура

| Путь | Что внутри |
| --- | --- |
| `src/chat.tsx`, `src/composer.tsx`, `src/message.tsx` | экран чата, поле ввода, рендер сообщений |
| `src/settings.tsx` | настройки: корневой список и подэкраны |
| `src/store.tsx` | состояние приложения, отправка сообщений, оба режима работы |
| `src/local-ai.ts` | потоковый клиент OpenAI-совместимого API |
| `src/catalog.ts` | сгенерированный каталог провайдеров и моделей |
| `src/tools.ts`, `src/app-tools.ts` | инструменты, доступные модели |
| `src/media.ts` | выбор файлов, вложения, скачивание на устройство |
| `src/clouds.ts`, `src/yandex.ts`, `src/gdrive.ts`, `src/dropbox.ts` | облачные хранилища |
